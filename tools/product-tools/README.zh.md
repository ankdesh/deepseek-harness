# 产品工具

[English](README.md) | 中文

## 概述

从已安装的 Harness 包准备命名产品配置并组装产品。本包没有运行时依赖，也不需要检出 Harness 源码。

## 配置准备

`prepareProductProfile(product, home, options)` 根据有序的 bundle 元数据创建命名配置。每个 bundle 必须导出包清单，并声明 `dsh.bundle.patch`。该函数创建受管理的链接，保留现有用户补丁，并拒绝覆盖受管理路径上的非链接文件。应用通过 `dsh --profile NAME` 启动结果。

## 发行文件组装

`assembleProduct` 检查发行清单的校验和以及已安装的 Harness 版本，然后遍历已安装的依赖、必需的对等依赖和可用的可选依赖。它将包复制到独立存储中，并在输出内部创建链接。它保留许可证文件并写入包清单。私有应用 bundle 必须声明 `files`；组装仅复制这些文件、包元数据和声明文件。输出目录必须是新目录。

调用方必须使用经过验证的生产锁文件安装依赖。仅检查版本不能验证已安装包的字节内容。通过干净注册表安装进行的验证以及归档校验和检查由发行流水线负责。

## 模型体验

本包不调用模型，也不修改提示词。它不会影响 token 或 KV 缓存。所选 bundle 决定应用可使用的服务。

## 已知限制与后续工作

首批发行支持使用 glibc 的 Linux x86-64。私有 bundle 文件列表仅接受正向相对路径模式；排除模式和包外路径会被拒绝。组装需要完整的已安装依赖集，不会下载缺失包。
