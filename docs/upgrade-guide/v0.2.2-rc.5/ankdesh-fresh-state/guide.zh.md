# 为 ankdesh-dsh 使用新的状态目录

[English](guide.md) | 中文

## 变更

此 ankdesh-dsh 版本写入会话格式 V4。旧分支写入 V3，其中包含上游转换器无法读取的必需工作流事件。旧状态目录也可能包含流程执行记录、事件代理和等待中的 HTTP 请求。

## 迁移

1. 保留旧数据目录和应用锁文件。用旧版本查看现有会话或完成旧运行。
2. 安装一组版本固定的 ankdesh-dsh 包。为升级后的 Web 或无界面配置使用新的空 DSH_HOME。
3. 启动配置并创建会话，再用升级后的运行时重新打开该会话。确认应用使用新目录。
4. 如需回滚，恢复旧锁文件，再使用原来的 DSH_HOME 启动旧运行时。
